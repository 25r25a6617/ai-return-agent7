# AI Return Agent

AI Return Agent is a Python-based application that helps users understand and query return policies using AI and Retrieval-Augmented Generation (RAG).

## Features

- AI-powered policy question answering
- Return policy information retrieval
- RAG-based search
- Python implementation
- Easy to extend and customise

## Project Files

- `app.py` - Main application
- `agent.py` - Agent logic
- `rag.py` - RAG implementation
- `date_tool.py` - Date utility functions
- `policies.txt` - Policy data
- `requirements.txt` - Project dependencies

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python app.py
```
